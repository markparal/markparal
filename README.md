## Featured work

### [mako-sgp4](https://github.com/markparal/mako-sgp4)

[![crates.io](https://img.shields.io/crates/v/mako-sgp4.svg)](https://crates.io/crates/mako-sgp4)
[![downloads](https://img.shields.io/crates/d/mako-sgp4.svg)](https://crates.io/crates/mako-sgp4)

A theory-based SGP4 propagator for TLEs and OMMs built in Rust. As of `v0.2.0`, it matches Vallado's reference implementation to within 1 mm. Built to make the underlying mathematics understandable and easy to follow.
